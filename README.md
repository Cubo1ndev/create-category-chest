# Create: Category Chest

Manage a Create stock ticker's Stock Keeper categories as a chest.

In Create, each category is three steps: click **+**, put the filter in, confirm. Here the categories *are* a 54-slot chest:

- **Drop filters in** to add categories, **take them out** to remove them, **drag them around** to reorder. Slot order is category order (gaps skipped).
- A category's name is its filter's custom name (rename filters on an anvil).
- Every change applies at once: there's no confirm button, and closing or disconnecting loses nothing.
- Categories each player hid stay hidden when you reorder.

## Opening it
- The **Category Chest** button next to Create's category screen.
- **Sneak + right-click** the stock ticker with **both hands empty**. Every other click does what Create does. Collecting payments stored in the ticker takes a normal click.

Only players allowed to use the ticker can open it, and only one at a time. Only Create filters (list, attribute and package filters) go in. A ticker with more than 54 categories shows the first 54 and keeps the rest after them.

## Requirements
NeoForge 1.21.1, Create 6.0.x. Needed on **both server and client**.
